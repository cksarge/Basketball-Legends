# MakeHuman assets (CC0 1.0)

`base.obj` and the `.target` files come from the MakeHuman project
(https://github.com/makehumancommunity/makehuman, `makehuman/data/`). The project
explicitly released them under CC0 1.0 Universal in September 2020.
`scripts/blender/build_player.py` uses them to build `public/models/player.glb`.
